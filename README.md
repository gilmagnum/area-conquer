# סוגר שטחים 🎯

משחק דפדפן בסגנון Qix/Xonix — צובעים שטח פתוח כדי לכבוש אותו, תוך התחמקות מכדורים קופצים. קובץ HTML בודד, בלי תלויות חיצוניות ובלי צורך ב-build — פותח את `index.html` בדפדפן ומתחילים לשחק.

🔗 גרסה חיה: הוסיפו קישור לאחר פרסום ב-GitHub Pages (למשל `https://gilmagnum.github.io/<שם-הריפו>/`)

## איך משחקים

- גוררים אצבע **מתוך שטח כבוש** (הקיר) אל השטח הפתוח וחזרה לשטח כבוש — התא שנסגר נכבש.
- נגיעה בקו שאתם מציירים באמצע ציור, או פגיעת כדור בקו/בעט — עולה לב.
- כובשים אחוז יעד מהשטח בשלב כדי לעלות הלאה. כל שלב מוסיף כדורים, מהירות ופלטת צבעים חדשה.
- הניקוד גדל ככל שמתקדמים: כל אחוז שטח שווה `1 × מספר השלב` נקודות, וכל בונוס שווה `5 × מספר השלב`.

## בקרה

- מגע וגרירה (טאץ') — בקרה עיקרית למובייל.
- גרירת עכבר — לבדיקה בדפדפן שולחני.
- אין מקלדת ואין כפתורי כיוון — הכול ציור חופשי ישירות על המסך.

## בונוסים

| אייקון | אפקט |
|---|---|
| 🛡️ | מגן זמני מפגיעת כדור |
| ❄️ | מקפיא את כל הכדורים לכמה שניות |
| ❤️ | חיים נוספים |
| 💣 | כיבוש אוטומטי של אזור עגול |

בונוס נאסף רק כשהשטח שסביבו נסגר בפועל ונהפך לשטח כבוש (לא מספיק לגעת בו עם הקו בעצמו).

## פיצ'רים טכניים

- Canvas 2D טהור, ללא ספריות.
- זיהוי כיבוש שטח באמצעות flood fill מנקודת מיקום הכדורים.
- פיזיקת כדורים עם זיהוי פגיעה בקיר בציר X/Y בנפרד (מונע "תקיעות" בפינות/דפנות).
- צלילים מסונתזים ב-Web Audio API (בלי קבצי אודיו חיצוניים), עם כפתור השתקה קבוע בפינת המסך.
- נעילת קלט זמנית לאחר פגיעה, כדי שלא ייספרו כמה פסילות מאותה נגיעה ברצף.
- 2 שניות המתנה עם ספירה לאחור בין שלבים.
